# VNA Tactical Console

Концепт-редизайн интерфейса векторного анализатора цепей, собранный в один самодостаточный HTML-файл.
Данные синтетические, интеракция настоящая. Представьте экран брифинга из *Call of Duty: Modern Warfare*,
только на нём S‑параметры полосового фильтра.

**[▶ Открыть живой прототип](https://htmlpreview.github.io/?https://github.com/vlad-bel/vna-test/blob/main/vna-prototype.html)**
— или скачайте `vna-prototype.html` и откройте двойным кликом. Без сборки, без зависимостей.

## Зачем

Настольные VNA до сих пор поставляются с интерфейсом, спроектированным вокруг физических софт-клавиш
эпохи HP/Agilent 1980-х, и крутятся на Windows Embedded и Intel Atom. Анализатор никто не покупает
за интерфейс, поэтому его никто и не переделывает. Это эксперимент: а что, если взять модель
взаимодействия из игр?

- **Цели вместо лимит-линий.** Лимит-тест превращается в чеклист с ✓ / ✕ и значением худшей точки.
- **Контекстная строка клавиш.** Нижний ряд показывает только те шорткаты, которые сейчас имеют смысл.
- **Лента событий.** Каждое действие оставляет строку в логе, как kill feed.
- **Два вида зума.** *Зум просмотра* растягивает уже измеренные точки (при сильном увеличении видны сами точки).
  *Apply as span* (Enter) пересвипывает видимое окно с полным разрешением. Мини-карта сверху всегда показывает, где вы.
- **Умные маркеры.** Снап к пику, поиск полосы −3 дБ, центрирование на маркере — по одной клавише.
- **Водопад.** Опциональная 2.5D-история развёрток, единственное «3D», которое влезает в бюджет.

## Управление

| Действие | Ввод |
|---|---|
| Зум по X вокруг курсора | Колесо мыши |
| Зум по Y | Shift + колесо |
| Панорамирование | Перетаскивание |
| Рамка зума | `Z`, затем растянуть прямоугольник (или Shift + drag) |
| Сброс вида / отмена вида | `Esc` / `Backspace` |
| Применить видимое окно как span | `Enter` |
| Полный диапазон | `F` |
| Число точек (201 → 1601) | `P` |
| Hold / Run | `Space` |
| Маркер → пик / полоса −3 дБ / центр | `M` / `B` / `C` |
| Автомасштаб Y | `A` |
| Водопад | `W` |
| Тач | Пинч для зума, drag для панорамы, маркеры перетаскиваются |

## Под капотом

Всё лежит в `vna-prototype.html`, примерно 550 строк:

- **WebGL 1 + GLSL** для фоновой сетки, свечения и сглаженных линий трасс (экструзия в triangle strip в вершинном шейдере). Цель — встроенные GPU класса Intel HD, 1280×800 / 60 fps при 1601 точке. Без полноэкранной постобработки.
- **2D-канвас поверх** для подписей осей, маркеров, перекрестия, сегментов лимита и рамки зума.
- **Синтетическая модель** полосового фильтра 1.5–4 ГГц с медленным дрейфом и шумом, чтобы трассы двигались как при настоящей развёртке.
- Цвета трасс следуют приборной конвенции (жёлтый S11, голубой S21, розовый S22), чтобы РЧ-инженер читал их без легенды.

## Статус

Одноразовый спайк. Не продукт, к железу не подключён. Если проект вырастет, следующий очевидный шаг —
разнести файл на модули и кормить его реальными развёртками с VNA по USB / Wi‑Fi.
